# Package scope

Included materials support local figure and table reproduction: the model
implementation, final configurations, calibrated parameters, simulation
results, distance data, inventory data and reference figures and tables.

The package excludes original CHA observations, model weights, large training
pools, complete execution logs, exploratory experiment records, working notes,
the working manuscript and cluster administration tools. Editable originals of
the two schematic diagrams are not included.

See [data sources](data-sources.md), [reproduction](reproduction.md) and
[model dependencies](../models/README.md) for details.
