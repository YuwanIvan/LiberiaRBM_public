# Reference figures and tables

The nine figure files match the manuscript reference figures. The eight table
`.tex` files contain the manuscript table environments; they require the
manuscript's macros and packages to compile.

The eight CSV files provide the notebook's numerical source views. The training
and baseline-parameter CSVs have different row layouts from the manuscript
tables. Use the LaTeX files to compare presentation and the CSVs to compare data.

[`docs/paper-assets.csv`](../docs/paper-assets.csv) maps manuscript labels to
reference files and generated outputs. Two schematic diagrams are supplied as
static references; their editable originals are not included.

Reference hashes identify these exact files. Regenerated PDFs may have different
metadata even when their plotted content agrees.
